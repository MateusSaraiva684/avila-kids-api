# API REST — Clientes e Favoritos

Atividade prática com Hono, Cloudflare Workers, D1 e Fake Store API.

API pública: https://avila-kids-api.mateussaraiva684.workers.dev

Consulte a [documentação completa](api/README.md) para os 11 endpoints, requisitos, configuração, testes e publicação.

```bash
cd api
npm ci
npm run db:local
npm run dev
```

Este repositório contém o código da API acadêmica. A interface Nuxt da loja Ávila Kids é independente e não integra esta entrega.
